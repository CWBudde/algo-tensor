# algo-tensor

Pure-Go tensor kernels and neural-network ops, shared by
[go-whistle](https://github.com/CWBudde/go-whistle) and [go-pocket-tts](https://github.com/CWBudde/go-pocket-tts):
GEMM, dot, axpy and their NEON/AVX2 assembly with pure-Go fallbacks, a bounded worker pool, and attention, RoPE and
1-D/2-D convolutions.

Status: being extracted from both projects.
